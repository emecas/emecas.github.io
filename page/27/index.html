InboxSDK

emecas published on 2022-10-12 included in JavaScript and Frontend Web and APIs

InboxSDK
Repo: https://github.com/inboxSDK/inboxsdk
Documentation: https://inboxsdk.github.io/inboxsdk-docs/
Doc repo: https://github.com/InboxSDK/inboxsdk-docs
The InboxSDK lets you build apps for Gmail.

InboxSDK is a JavaScript library for building apps inside Gmail with browser extensions. It features a high-level declarative API that handles all DOM manipulation in a performant way. InboxSDK can handle multiple inboxes, conversation mode, fullscreen compose, popouts, and themes.
