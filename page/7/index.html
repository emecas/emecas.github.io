oha
https://github.com/hatoo/oha
Ohayou(おはよう), HTTP load generator, inspired by rakyll/hey with tui animation.

oha is a tiny program that sends some load to a web application and show realtime tui inspired by rakyll/hey.

This program is written in Rust and powered by tokio and beautiful tui by ratatui.

Hey

emecas published on 2024-10-17 included in Testing and Code Quality Web and APIs Developer Tools

Hey
https://github.com/rakyll/hey

hey is a tiny program that sends some load to a web application.

hey was originally called boom and was influenced from Tarek Ziade’s tool at tarekziade/boom.

Using the same name was a mistake as it resulted in cases where binary name conflicts created confusion.
To preserve the name for its original owner, we renamed this project to hey.

Previously known as github.com/rakyll/boom.

Source: commit a637379 in My-Notes.
