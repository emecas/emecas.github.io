Recover MySQL root Password
https://www.cyberciti.biz/tips/recover-mysql-root-password.html1
cyberciti.biz:

You can recover MySQL database server password with following five easy steps.

The five steps: stop the MySQL server; start it again with --skip-grant-tables, so it asks for no password; connect as root with mysql -u root; set a new password for root; stop the server and start it normally.
