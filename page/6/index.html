OpenTelemetry
https://opentelemetry.io/
The open standard for telemetry

OpenTelemetry (OTel) is a leading open-source framework designed to help developers monitor and understand the performance of complex, cloud-native applications. It was created by merging two major projects, **OpenTracing** and **OpenCensus**, under the Cloud Native Computing Foundation (CNCF).

Here is a breakdown of why it’s a big deal in the software world:

### Core Benefits

* **Vendor Neutrality:** You can instrument your code once and send your data to any backend (like Prometheus, Jaeger, or commercial tools). This prevents “vendor lock-in,” allowing you to switch providers without rewriting your application code.
* **Unified Signals:** It brings together **Traces** (the journey of a request), **Metrics** (performance data over time), and **Logs** (timestamped events) into a single, correlated view.
* **Broad Support:** It offers native SDKs for over 12 programming languages and features more than 900 integrations.

Apache Superset
https://superset.apache.org/
Apache Superset is an open-source modern data exploration and visualization platform.

Key features

• 40+ pre-installed visualizations
• Support for drag-and-drop and SQL queries
• Data caching for the faster load time of charts and dashboards
• Jinja templating and dashboard filters for creating interactive dashboards
• CSS templates to customize charts and dashboards to your brand’s look and feel
• Semantic layer for SQL data transformations
• Cross-filters, drill-to-detail, and drill-by features for deeper data analysis
• Virtual datasets for ad-hoc data exploration
• Access to new functionalities through feature flags
