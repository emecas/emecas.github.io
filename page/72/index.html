How to Sync Issues to/from Mirror Repo?

Comment on 2020-02-13:
github

curl -i “https://api.github.com/repos/<repo-owner>/<repo-name>/issues” -u “<user-name>”

curl -i “https://api.github.com/repos/emecas/commitit/issues” -u “emecas”

gitlab

https://docs.gitlab.com/ee/api/issues.html

curl --header “PRIVATE-TOKEN: <your_access_token>” https://gitlab.example.com/api/v4/issues

New Issue:

https://docs.gitlab.com/ee/api/issues.html#new-issue

POST /projects/:id/issues

curl --request POST --header “PRIVATE-TOKEN: <your_access_token>” https://gitlab.example.com/api/v4/projects/4/issues?title=Issues%20with%20auth&labels=bug

Comments on issues

https://docs.gitlab.com/ee/api/issues.html#comments-on-issues

Comments are done via the notes resource

https://docs.gitlab.com/ee/api/notes.html
