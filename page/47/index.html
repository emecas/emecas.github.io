https://github.com/architect/architect

Deno is a brand new experimental JavaScript runtime and deno.town is a web based REPL with linting and code completion to help you explore and learn the API.
Why Deno?

It is very fast
Built in least privilege security
Standard esmodules
TypeScript, JSX and TSX dialects supported

How

AWS Lambda (and friends) by way of OpenJS Architect
Deployed continuously with begin.com (Note! We have not officially released Deno support. Keep reading if you are interested in that.)
