Moving from Buttercup to KeePassXC: not by choice, but by necessity

For a long time Buttercup was my password manager. It was simple, open source, and it fit the way I worked. So when its maintainer, Perry Mitchell, announced on March 3, 2025 that the project was ending, it wasn’t something I could ignore. He explained that since co-founder Sallar left, he had been the only active maintainer, and that the project’s scope, across operating systems, mobile platforms and third-party services, with ongoing security requirements, was too much for one person. On June 26, 2025 the desktop app’s repository was archived and is now read-only, like the rest of the project.

Why I moved anyway

My Buttercup install still works: Buttercup is not a hosted service, and vaults live in your own storage. But a password manager that no longer gets security fixes isn’t one I want to trust. The mobile apps are expected to stop working first, followed by the browser add-ons. The author himself advised users to plan a move to a password manager they can self-host, and he has more than 600 entries of his own to migrate.

KeePassXC

So I’ve switched to KeePassXC. It’s free, open source, ad-free and cloud-free. It uses the KDBX format and has browser integration, TOTP, auto-type, SSH agent support and password health reports. In its own words:

Let KeePassXC safely store your passwords and auto-fill them into your favorite apps, so you can forget all about them.

We do the heavy lifting in a no-nonsense, ad-free, tracker-free, and cloud-free manner. Free and open source.

KeePassXC has been awarded a Security Visa by the French National Cybersecurity Agency (ANSSI).

New habits

I’ve only just started, and so far it feels less like a new tool and more like learning new habits. Things I used to do automatically now take a moment of thought: how entries and groups are organised, how auto-fill and auto-type behave, how I sync my database. For now I’m deliberately taking it slowly, rebuilding my routine one step at a time.

If you’re moving too

If you haven’t moved your data yet, there’s a community tool, bcup2kdbx ★ star note, that converts a Buttercup vault (.bcup) into a KDBX 4 database for KeePassXC, keeping groups, fields, attachments and trash. It’s third-party and new, so check it before you use it.

KeePassXC’s features

From the features list ★ star note in its repository:

Core features

  • Create, open, and save databases in the KDBX format (KeePass-compatible with KDBX4 and KDBX3)
  • All information is encrypted at rest and never exposed outside the program
  • Store sensitive information in entries that are organized by groups
  • Password generator
  • Search for entries
  • TOTP storage and generation
  • YubiKey/OnlyKey challenge-response support
  • Auto-Type passwords into applications
  • Browser integration with Google Chrome, Mozilla Firefox, Microsoft Edge, Chromium, Vivaldi, Brave, and Tor-Browser
  • Support for passkeys using the browser integration
  • Entry icon download
  • Import databases from CSV, 1Password, Bitwarden, Proton Pass, and KeePass1 formats

Advanced

  • Database reports (password health, HIBP, and statistics)
  • Database export to CSV, XML, and HTML formats
  • TOTP storage and generation
  • Field references between entries
  • File attachments and custom attributes
  • Entry history and data restoration
  • Command line interface (keepassxc-cli)
  • SSH Agent integration
  • FreeDesktop.org Secret Service (replace Gnome keyring, etc.)
  • Additional encryption choices: Twofish and ChaCha20
